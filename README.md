### 💻 Projetos

#### BarberFlow

Sistema web para gerenciamento de filas de espera e agendamentos para barbearias.

O projeto foi desenvolvido com foco em organizar o atendimento da barbearia,
facilitar o gerenciamento da fila e fornecer ao administrador informações
sobre atendimentos, serviços e faturamento.

**Tecnologias:** Next.js, React, Tailwind CSS, Python, FastAPI e MongoDB.

---

#### LojaDiPaula

Website para uma confeitaria, desenvolvido com foco em apresentação dos produtos,
experiência do usuário e conversão de clientes através do WhatsApp.

O projeto busca reduzir o caminho entre o interesse pelo produto e o contato
comercial, facilitando o processo de pedido através do WhatsApp.

**Tecnologias:** Next.js, React, TypeScript e Tailwind CSS.

---

#### Sistema para loja de roupas — Em desenvolvimento

Projeto planejado para uma loja de roupas, com foco em automatizar etapas do
processo de venda e melhorar a conversão de visitantes em clientes.

O projeto está em fase de planejamento e estudo da arquitetura, fluxo de vendas
e estratégias para tornar o processo de compra mais eficiente.
